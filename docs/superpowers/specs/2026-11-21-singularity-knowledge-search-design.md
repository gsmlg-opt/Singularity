# 知识库搜索

`/knowledge` 是所有知识类型的搜索入口。沿用应用导航，内容区默认居中显示 Singularity SVG 字标和一个搜索框。按 Enter 或点击搜索图标提交。关键词保存在 `q` 参数中，刷新和浏览器前进、后退可以恢复搜索。结果页显示搜索框和结果，清空查询后恢复字标。

在同一结果表格中显示各类知识，标明类型，并链接到各自的详情页。查询的词项都要匹配，可以分布在标题、标识符、摘要、正文、README 或说明中。查询也可以按字面子串匹配标题、标识符和摘要。正文使用 PostgreSQL 的全文索引。标题和标识符命中优先，同等相关度按加入时间及 ID 排序。每页显示 30 条，有更多结果时可以翻页。无匹配时显示提示，提交空白时返回搜索入口。

软件项目和 RFC 的分类浏览仍通过各自的侧栏链接进入。概览的项目和项目 label 链接进入软件项目列表。
