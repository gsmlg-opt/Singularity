# Software project search

On the knowledge index, present search as the widest control in a compact toolbar. Keep its existing debounce, sort choices, status choices and URL parameters. At phone widths the query occupies its own row. Show the number of matching projects across all pages and offer a reset when the user changes the filters or sort order.

Give the project title and one-line description the widest column. Place exceptional states beside the project information. Show language and stars separately. Preview two labels in each row, prioritizing manual labels and then labels that add information beyond the language column. A keyboard-accessible disclosure reveals the remaining labels in place. The Overview uses this same project table.

Verify the search on both knowledge routes, including zero matches, combined filters, the last full page, reset and live updates. Check the existing theme pairs and the table at desktop and phone widths with populated data.
