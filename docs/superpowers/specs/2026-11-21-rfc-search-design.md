# RFC search

Use the knowledge search toolbar for the RFC index. The full-width input accepts a number such as `8446` or `RFC 8446`, or words from a title. Show the matching count beside the heading and offer a reset when a search or label is active. Removing only the label keeps the query.

Each result links its RFC number and full title to the document. Show the publication month and status, with the status acting as a filter when the record has an automatic status label. Keep its other labels visible. On narrow screens, place the title above the metadata and allow long titles to wrap. Retain the existing highest-number-first ordering, pagination and URLs.
